Cloud Link Workflow

Open Cloud Link Support

Transmittal Manager is not limited to one cloud provider. Each submission can store a project share link from the platform already approved by the office or client.

Platform typeExamplesHow it is used
Construction cloudAutodesk Docs, Autodesk Construction Cloud, BIM 360Paste the drawing package share link into the submission record.
Office cloudSharePoint, OneDrive, Google Drive, DropboxUse the folder or file link that the recipient is allowed to open.
Private cloudNextcloud, ownCloud, company-hosted portalsStore the public or controlled share link and generate a QR code in the transmittal note.
Local serverUNC paths such as \\SERVER\Projects\...Store the internal folder path for office reference and complete log export.

QR Code Use

When a cloud URL is entered in a transmittal, the exported transmittal note can include a QR code. The recipient can scan it to open the package link from a phone or tablet.

Recommended Office Rule

Keep the app as the official record of what was sent, and keep the cloud platform as the file delivery location. This keeps issue history searchable even if folders are moved later.
