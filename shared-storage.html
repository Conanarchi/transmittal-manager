Shared Office Storage

How It Works

By default, each installation stores its database locally. In Company Settings, the office can choose a shared server folder. The app then uses a database file named transmittal-manager.db in that shared location.

Recommended Folder

Use a stable server path that all document-control users can access, for example:

\\SERVER\Projects\Document Control\Transmittal Manager Data

What Is Stored

DataStorage method
Projects, sheets, revisions, transmittals, cover lettersStored inside the SQLite database file.
Signed transmittal notesCopied into the shared data folder under Signed Transmittals.
Signed cover lettersCopied into the shared data folder under Signed Cover Letters.
Exported documentsSaved wherever the user chooses during export; paths are kept in the database.

Good Practice

  • Give all users read/write permission to the selected folder.
  • Back up the shared folder daily with the office server backup.
  • Avoid editing the same record on two computers at exactly the same time.
  • Keep exports and signed files in structured project folders.
