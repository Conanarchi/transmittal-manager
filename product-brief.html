Transmittal Manager Product Brief

Purpose

Transmittal Manager is a Windows desktop application for architecture, engineering, interior design, and construction teams that need reliable drawing issue records without using a heavy enterprise document-control platform.

What It Manages

AreaWhat the app does
ProjectsStores project code, project name, client contact details, and project status.
Drawing RegisterStores sheets by discipline with drawing number, description, scale, current revision, last sent date, and history.
TransmittalsCreates draft and issued transmittals, exports transmittal notes, detailed drawing lists, and complete logs.
Cover LettersCreates separate outgoing letters with automatic references, sender details, Arabic support, archive status, and signed copy storage.
AttachmentsStores file paths to signed notes and signed cover letters so records can be opened later.

Ideal Users

  • Document controllers preparing regular drawing submissions.
  • Architectural and engineering offices tracking revisions across several projects.
  • Project managers who need a searchable record of what was sent and when.
  • Small contractors or consultants who want structured logs without a large EDMS subscription.

Core Value

The application reduces repeated typing, keeps issue records consistent, makes revision history easier to audit, and keeps signed evidence attached to the same record used for export.
